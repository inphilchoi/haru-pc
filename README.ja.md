# Haru PC

[English](README.md) · [한국어](README.ko.md) · **日本語** · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português](README.pt-BR.md)

**スマホで Haru に頼めば、作業はパソコンがこなします。**

Haru PC（ハル）は、**Haru – AI アシスタント**（iPhone・Android）と連携するデスクトップアプリです。スマホで Haru に「パソコンの Reports フォルダを整理して」「先月の請求書を探して送って」のように頼むと、Haru PC がお使いのパソコン上でその依頼を受け取って実行し、結果をスマホに返します。

Haru PC は、オープンソースのパーソナル AI アシスタント [OpenClaw](https://github.com/openclaw/openclaw)（MIT ライセンス）の上で動作します。インストーラーが動作検証済みのバージョンの OpenClaw をセットアップし、その上に Haru PC プラグインを追加します。プラグインには、Haru のアシスタント・ペルソナ、スマホでの承認による安全機構、すぐに使えるスキル一式が含まれています。Haru PC は非公式のディストリビューションであり、OpenClaw プロジェクトとは提携していません。

> **ステータス:** アーリープレビュー版です。至らない点もあるかと思いますので、問題を見つけたらぜひお知らせください。

## しくみ

```
 Haru アプリ（スマホ）                          Haru PC（パソコン）
 ─────────────────────                          ───────────────────────
 「パソコンの Reports フォルダを整理して」
   → カード:「PC に送りますか？」[実行]
   ── 直接接続・クラウド中継なし ───────────────▶ タスクを受け取る
                                                  手順を計画する
   ◀── 「ファイルを 12 個移動します。OK？」 ───── 危険な操作の前に確認
   [承認]  ─────────────────────────────────────▶ 作業を実行
   ◀── 「完了: 12 個移動、重複 3 個」 ─────────── 結果を送信
```

- **スマホはお使いのパソコンと、暗号化された接続で直接やり取りします。** 同じ Wi-Fi 上なら自動的にお互いを見つけます。外出先からは、ご自身の [Tailscale](https://tailscale.com) ネットワーク経由で接続できます。私たちが運営するサーバーは一切経由しません。
- **あなたの許可なしには何も実行されません。** ファイルの変更、コマンドの実行、メッセージの送信、ブラウザの操作といったアクションは、すべて先にスマホにカードとして表示されます。**承認** をタップしたときだけ実行されます。
- **データはあなたのものです。** 会話、メモリ、認証情報は、お使いのパソコンとスマホにのみ保存されます。

## Haru PC でできること

| スマホで頼むこと | Haru PC が行うこと |
|---|---|
| 「ダウンロードフォルダを整理して」 | ファイルを種類と日付ごとにフォルダへ振り分け、重複ファイルを報告します |
| 「先週の契約書の PDF を探して送って」 | ファイルを検索し、そのファイルをスマホに送ります |
| 「この議事メモを Word 文書にして」 | 書類フォルダに `.docx` を作成します |
| 「デスクトップにあるスプレッドシートを要約して」 | ファイルを読み込み、短い要約で返信します |
| 「この商品の値段を 3 つのサイトで比べて」 | ブラウザを開いて比較し、返信します。ブラウザスキルはご自身でオンにするまでオフのままで、支払いは一切行いません |
| 「毎週月曜 9 時に、今週変更したファイルを一覧にして」 | パソコン上で実行されるルーティンを設定します |

スキルは追加でき、オン・オフも切り替えられます。詳しくは [スキル](#スキル) をご覧ください。

## 必要なもの

- スマホにインストールした **Haru アプリ**（iPhone・Android。App Store と Google Play で近日公開予定）
- Haru PC に作業を任せている間、**電源が入ったままのパソコン**:
  - **macOS** 13 以降（Apple シリコンまたは Intel）
  - **Windows** 10/11（64 ビット）。ネイティブで動作するため、WSL は不要です
  - `systemd` を使う **Linux**: Ubuntu 22.04 以降、Debian 12 以降、Fedora など。クラウドモデルを使うなら Raspberry Pi 4/5（64 ビット、2 GB 以上）でも動作します
  - **Node.js 24** 以降。入っていなければインストーラーが自動でインストールします
- ご自身で選ぶ **AI モデル**:
  - **クラウドモデル**: すでに契約している ChatGPT、Claude、GitHub Copilot のサブスクリプションでサインインするか、API キーを使います（例: Gemini）。最も高品質です。
  - パソコン上で動く **ローカルモデル**（llama.cpp または [Ollama](https://ollama.com)）。無料で完全にプライベートですが、動作は遅めです。RAM 16 GB なら、実用上はパラメーター数 90 億（9B）程度のモデルが上限です。安全のため、小さなローカルモデルには、設定を変更しない限り読み取り専用のスキルだけが割り当てられます。

### おすすめの構成

Haru PC を置くなら、**Mac mini**（または常に電源が入っているパソコン）がいちばん快適です。消費電力が少なく、画面なしでも動き、RAM が 16 GB 以上あれば無料のローカルモデルも動かせます。スマホの Haru アプリと一度ペアリングしたら、あとは電源を入れたままにしておくだけです。

## インストール

### macOS と Linux

```bash
curl -fsSL https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.sh | bash
```

### Windows（PowerShell）

```powershell
irm https://raw.githubusercontent.com/inphilchoi/haru-pc/main/install.ps1 | iex
```

インストーラーは次の処理を行います。
1. 必要に応じて Node.js をインストールし、続いて動作検証済みでバージョンを固定した OpenClaw をインストールします。
2. Haru PC プラグインと標準スキルを追加します。
3. 安全な設定を適用します。コマンド実行時の承認を必須にし、暗号化接続（TLS）とローカルネットワーク検出をオンにします。
4. Haru PC がバックグラウンドで起動するよう登録します（macOS では launchd、Windows ではタスクスケジューラのタスク、Linux では `systemd --user` サービス）。
5. AI モデルの選択を手伝ったあと、ペアリング用の QR コードを表示します。

先にスクリプトの中身を確認したい場合は、[`install.sh`](install.sh) または [`install.ps1`](install.ps1) をダウンロードして確認してから実行してください。各プラットフォーム向けのインストーラーパッケージは [Releases](https://github.com/inphilchoi/haru-pc/releases) ページからも入手できます。

## スマホを接続する

1. スマホで **Haru** を開き、**「パソコンに接続して」** と話しかけます（または ⚙ → **Haru PC** をタップします）。
2. インストーラーが表示した QR コードを読み取ります。コードの有効期限は 10 分で、使えるのは 1 回だけです。新しいコードを表示するには、次を実行します。
   ```bash
   haru-pc pair
   ```
3. パソコンに **「このスマホを接続しますか？」** と表示されます。これを承認し、両方の画面のセキュリティコードが一致していることを確認すれば完了です。

**外出先から使うには:** スマホとパソコンの両方に [Tailscale](https://tailscale.com) をインストールして同じ tailnet にサインインし、`haru-pc remote on` を実行してください。これで Haru PC には、ご自身の tailnet の中からだけアクセスできるようになります（Tailscale Serve）。Haru PC がインターネットに向けてポートを開くことはありません。

## AI モデルを選ぶ

インストール時にひとつ選び、あとからいつでも変更できます。

**すでに契約している AI サブスクリプションでサインインできます。** Haru PC があなたのパスワードを尋ねることはありません。サインインは各プロバイダーの公式ページで行い、Haru PC は必要な権限だけを受け取ります。

| プロバイダー | 接続方法 |
|---|---|
| **ChatGPT**（OpenAI） | `haru-pc model login chatgpt` を実行し、OpenAI のページでサインインします。ご契約中の ChatGPT プランの利用上限が適用されます |
| **Claude**（Anthropic） | Anthropic 公式の Claude CLI で一度サインインしてから（`claude auth login`）、`haru-pc model login claude` を実行します。ご契約中の Claude プランの利用上限が適用されます。プランをほかのツールで使うことについては、Anthropic の最新の規約をご確認ください |
| **GitHub Copilot** | `haru-pc model login copilot` を実行し、GitHub のページに表示されたコードを入力します |

**API キーを使うこともできます**（Anthropic、OpenAI、Google Gemini、Mistral、DeepSeek など）。

```bash
haru-pc model key openai      # 求められたらキーを貼り付けます
haru-pc model key gemini
```

Google Gemini は API キーでのみ接続できます。キーは Google AI Studio で無料で取得できます。

**パソコン上でローカルモデルを動かすこともできます。** 無料でプライベートです。

```bash
haru-pc model local           # お使いのパソコンに合ったモデルをおすすめします
```

```bash
haru-pc model                 # 現在のモデルを表示
```

サインイン情報とキーは OS のセキュアストレージ（キーチェーン、Windows 資格情報マネージャー、Linux では libsecret）に保管されます。スマホや私たちに送信されることはありません。

### 中国本土では

OpenAI、Anthropic、Google は中国本土でモデルを提供していません。代わりに現地で使えるプロバイダーを選んでください。たとえば DeepSeek、Qwen（Alibaba）、Kimi（Moonshot）、Doubao（Volcano Engine）、ERNIE（Baidu Qianfan）、MiniMax、Zhipu GLM などを `haru-pc model key <provider>` で設定できます。インターネットに接続しなくても動くローカルモデルを `haru-pc model local` で使う方法もあります。

## スキル

スキルは、Haru PC に仕事を教えるための、小さくて読みやすい指示のパッケージです。`~/.haru-pc/skills/` に置かれ、OpenClaw のスキル形式に従います。

```bash
haru-pc skills                # インストール済みのスキルを一覧表示
haru-pc skills enable office  # スキルをオンにする
haru-pc skills disable browser
```

標準スキル:

| スキル | 内容 |
|---|---|
| `files` | ファイルの検索・移動・名前変更・整理。重複ファイルも報告します |
| `send-to-phone` | ファイルや要約を Haru アプリに送ります |
| `office` | Word、Excel、PowerPoint、PDF の文書を作成・読み込みします |
| `browser` | 調べものやページの比較を行います。**初期設定ではオフです。** 支払いは一切せず、確認なしにログインすることもありません |
| `routines` | スケジュールに沿ってタスクを実行します（「毎週月曜 9 時」など） |

Haru PC には独自に審査済みのスキルが付属しており、公開マーケットプレイスのスキルを自分でインストールすることはありません。新しいものをインストールするには、必ずスマホでの承認が必要です。

独自のスキルを作ることもできます。[docs/skills.md](docs/skills.md) をご覧ください。

## 安全性

Haru PC はパソコン上で実際に操作を行えるため、慎重に動くよう設計されています。

- 何かを変更する **すべての操作にスマホでの承認が必要** です。ファイルの書き込みや移動、コマンドの実行、ブラウザの使用、ファイルの送信が対象です。何が実行されるのかを正確に確認したうえで、**今回のみ許可** か **拒否** を選びます。「常に許可」はありません。
- **メッセージは信頼できない入力として扱います。** ファイル、Web ページ、メールに含まれるテキストが Haru PC に新しい指示を与えることはできません。それらはデータとして扱われるため、プロンプトインジェクションを防げます。
- **フォルダの許可リスト。** 初期設定では、Haru PC は `Documents`、`Downloads`、`Desktop` の中でのみ作業します。変更するには `haru-pc allow <folder>` を使います。
- **支払い・送金はしません。** Haru PC が購入、支払い、送金を行うことはありません。
- **ペアリングが必須。** タスクを送れるのはペアリング済みのスマホだけです。`haru-pc unpair` でいつでもペアリングを解除できます。
- **ローカルネットワークか、ご自身の tailnet 内だけ。** Haru PC がインターネットに公開されることはありません。
- **バージョン固定とセキュリティ監査。** インストーラーは動作検証済みの OpenClaw バージョンを使い、最後に OpenClaw のセキュリティ監査を実行します。`haru-pc update` を実行すると、次の検証済みバージョンに更新されます。

セキュリティ上の問題を見つけた場合は、公開の Issue を立てるのではなく **creativelab.choi@gmail.com** までメールでご連絡ください。

## アップデートとアンインストール

```bash
haru-pc update       # Haru PC とスキルをアップデート
haru-pc uninstall    # バックグラウンドサービスを停止し、Haru PC を削除
```

設定は、`~/.haru-pc` フォルダを削除するまで残ります。

## トラブルシューティング

| 症状 | 対処法 |
|---|---|
| スマホがパソコンを見つけられない | 両方が同じ Wi-Fi に接続されているか、両方が Tailscale にサインインしているかを確認し、`haru-pc status` を実行してください |
| ペアリング用 QR コードの期限が切れた | もう一度 `haru-pc pair` を実行してください |
| タスクの処理が遅い | 性能の低いマシンではローカルモデルの動作が遅くなります。`haru-pc model login chatgpt` または `haru-pc model login claude` でサブスクリプションにサインインしてください |
| 承認カードが届かない | 承認のリクエストは、Haru アプリを開いているときにスマホに届きます。10 分以内に応答がないと Haru PC はリクエストを取り下げ、何も実行しません。Haru を開いて、もう一度頼んでください |
| 何かがうまくいかない | `haru-pc logs` を実行し、その出力を Issue に添付してください |

## プライバシー

Haru PC にはアカウントがなく、私たちのサーバーもありません。タスク、ファイル、メモリ、キーはすべてお使いのデバイス上にとどまります。クラウドの AI モデルを選んだ場合、タスクのテキストはそのプロバイダーの規約に従って送信されます。ローカルモデルなら、データがパソコンの外に出ることはありません。
